# Package Catalog

The official Detian package surface spans framework, data, persistence, graph/AI, visualization, and utility layers.

This section includes:

- an overview page
- one page per package
- generated API inventories from package source files

## Main families

- Framework: `hya`, `webkit`, `builtin`
- Persistence/Data: `db`, `queuex`, `cachex`, `tabular`, `jsonx`, `filex`, `datetime`, `uuidx`
- Security/Auth: `crypto`, `authx`
- Visualization/UI: `chart`, `flowviz`, `renderx`, `imgx`, `svgx`
- Graph/AI: `graph`, `llmx`, `aix`, `ezml`, `visionx`
- Numerical: `mathx`, `ndx`, `statsx`, `sciencex`
- Applied ML: `ezml` (built around numeric/tabular baseline workflows)
- Tooling/CLI/Test: `clix`, `regex`, `httpx`, `testx`, `metricsx`
