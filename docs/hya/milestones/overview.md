# Milestones Overview

The fine-grained renderer was intentionally built as a sequence of vertical slices.

- Milestone A: text hydration MVP
- Milestone B: attr/class/style
- Milestone C: conditional + keyed each
- Milestone D: state/action bridge integration + safe HYX lowering
- Milestone D2: generic keyed template expansion
- Milestone D4: optimistic updates and reconcile
- Milestone E: developer ergonomics and inspectability

Use the pages in this section as implementation checkpoints.
